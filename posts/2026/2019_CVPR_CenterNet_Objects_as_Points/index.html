CenterNet Objects as Points

2026年01月18日

Task: Object Detection
Method: anchor-free, keypoint
Venue: CVPR
Year: 2019
Paper: https://arxiv.org/abs/1904.07850
Code: https://github.com/xingyizhou/CenterNet

问题描述

传统方法（Faster R-CNN、RetinaNet）依赖 anchor box，存在：

  • 需要人工设计 anchor 尺度和比例
  • 正负样本不平衡
  • 推理复杂（NMS、proposal 生成）

核心思想

将目标检测建模为 “预测物体中心点” 的关键点检测问题。

方法概述

整体流程：

  1. 使用全卷积网络（Hourglass / DLA）输出 heatmap
  2. 每个物体只用一个中心点表示
  3. 在中心点位置预测：
    • 目标类别（heatmap）
    • 尺寸（width, height）
    • 亚像素偏移（offset）

关键输出头：

  • Center heatmap：每个类别一个通道
  • Size head：预测目标宽高
  • Offset head：修正下采样带来的量化误差

创新点

  1. 将目标检测彻底转化为 关键点检测问题
  2. 完全 Anchor-free / Proposal-free
  3. 用单一中心点表示目标，结构极简
  4. 使用 focal-like loss 解决中心点稀疏问题

实验结论

Datasets: MS COCO, KITTI (3D), nuScenes

最佳结果:

  • MS COCO: CenterNet (Hourglass-104) 达到 45.1% AP（当时接近SOTA）
  • 速度: ResNet-18 backbone 可达 142 FPS，DLA-34 达到 52 FPS
  • 多任务: 可同时完成检测、3D检测、姿态估计

消融研究:

  • Offset head 对精度有明显提升（+1.2 AP）
  • Heatmap Gaussian kernel 的 sigma 对性能影响较大
  • 不同 backbone 的性能/速度 trade-off 明显：
    • ResNet-18: 快速但精度较低（28.1% AP）
    • DLA-34: 平衡选择（37.4% AP）
    • Hourglass-104: 最高精度但较慢（45.1% AP）

局限性

  • 密集/遮挡目标表现差
  • 极小目标需要高分辨率（<50px 精度下降明显）
  • 中心点重叠时易混淆；极端长宽比边界不准

复杂度分析

参数量（以 COCO 80 类为例）：

  • ResNet-18: ~13.6M 参数，~12 GFLOPs
  • DLA-34: ~15.3M 参数，~14 GFLOPs
  • Hourglass-104: ~50M 参数，~40 GFLOPs

内存占用：

  • 训练（batch=16）：6GB（ResNet-18），12GB（Hourglass）
  • 推理：<1GB（单张图片）

工程应用

效率对比表：

方法 AP FPS 参数量 特点
Faster R-CNN 36.5 5 137M 两阶段，需要NMS
RetinaNet 40.8 15 88M 一阶段，Anchor-based
CenterNet-Res18 28.1 142 13.6M 轻量，速度优先
CenterNet-DLA34 37.4 52 15.3M 平衡方案
CenterNet-Hourglass 45.1 7.8 50M 最优精度

训练成本：

  • ResNet-18/34: 轻量级，单卡 1080Ti 训练 1-2 天
  • DLA-34: 中等，单卡 V100 训练约 2-3 天
  • Hourglass-104: 重量级，多卡训练 3-5 天

推理速度：

  • ResNet-18: ~142 FPS（512×512输入）
  • DLA-34: ~52 FPS
  • Hourglass-104: ~7.8 FPS
  • 无需 NMS，后处理极快（<1ms）

实现细节：

  • 基础增强：随机裁剪/翻转
  • 学习率调度：多步衰减（epoch 90, 120）
  • Heatmap sigma=2，loss权重（cls:1, reg:0.1）

超参数分析：

  • sigma 范围 1-3 最优
  • 输入分辨率影响大（256→512 提升 8% AP）

工业应用：

  • 非常高：已被多个工业项目采用（如 MMDetection）
  • 易于部署到边缘设备（TensorRT、ONNX 支持良好）
  • 可扩展性强：容易添加额外任务（如关键点、3D 框）
  • 适合实时应用场景（监控、机器人、移动端）

相关工作

类似方法：

  • CornerNet（预测角点）：需要匹配成对的角点，更复杂
  • ExtremeNet（预测极值点）：需要预测5个点并组合
  • FCOS（预测中心度）：也是 anchor-free 但基于密集预测

优点：无需匹配keypoints；无需NMS
缺点：复杂形状/旋转目标性能差；重叠目标无法区分

研究启示

  1. “降维”思想：4D框简化为2D点检测，降低设计复杂度
  2. Heatmap稳定性：”软”监督信号对噪声标注更鲁棒
  3. 多任务扩展性：易扩展到3D检测、姿态估计等

复现注意事项

  1. Heatmap生成：sigma值关键，可视化验证后再训练
  2. Loss权重：heatmap=1, offset=1, size=0.1；可根据数据微调
  3. 峰值提取：3×3 max pooling 找局部最大值

改进与优化方向

改进方向:

  • Attention 机制：用 CBAM 或 Self-Attention 增强特征表达
  • 多尺度融合：在多个尺度预测中心点，类似 FPN 的设计
  • Deformable 卷积：增强对非刚性变形、遮挡的适应性
  • 动态 Gaussian：根据目标尺寸动态调整 heatmap 的 sigma

简化方向:

  • 去除 Offset：快 10%，精度 -1.5 AP
  • 轻量 Backbone：MobileNet / EfficientNet-Lite
  • 单尺度训练：固定输入尺寸，简化数据处理

论文价值与启示

  • CenterNet 的 “Object = Point” 思想极具抽象性和优雅性
  • 非常适合作为 anchor-free 检测的入门基线（代码清晰，易理解）
  • 对后续工作影响深远：DETR、FCOS、TTFNet 等都受其启发
  • 实用性强：在工业界广泛应用（监控、自动驾驶、机器人）
  • 是否值得复现：强烈推荐（结构简单、训练稳定、扩展性好）
  • 适合作为研究新方法的 baseline，也适合直接用于生产环境
  • 理解 CenterNet 有助于理解现代检测器的设计哲学
